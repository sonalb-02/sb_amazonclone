# Amazon Clone

A front-end Amazon Clone built using **HTML and CSS**, designed to recreate the look and feel of Amazon's online shopping website.

## About the Project
This project is a simple e-commerce website UI inspired by Amazon. It was created to practice web development fundamentals, including HTML structure, CSS styling, layouts, and responsive design.

## Features
- Amazon-inspired homepage layout
- Search bar UI
- Product categories and shopping cards
- Navigation bar and shopping cart section
- Styled using CSS
- Responsive design 

## Technologies Used
- **HTML5** – For structuring the webpage
- **CSS3** – For styling and layout

## Project Structure
Amazon-Clone
├── index.html
├── style.css
├── images/
└── README.md

## Getting Started
1. Clone this repository:
   git clone YOUR_REPOSITORY_URL
2. Open the project folder.
3. Open `index.html` in your browser to view the website.
